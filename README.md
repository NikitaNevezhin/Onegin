# 🪶 Onegin Sorter

[![Language](https://shields.io)](https://wikipedia.org)
[![License](https://shields.io)](LICENSE)

Низкоуровневый текстовый процессор на языке **C**, разработанный для эффективного анализа, индексации и кастомной сортировки больших текстовых массивов. Изначально спроектирован для обработки поэтических текстов (таких как роман А. С. Пушкина «Евгений Онегин»).

Проект демонстрирует продвинутую работу с динамической памятью (`heap`), арифметикой указателей и оптимизацией дискового ввода-вывода (I/O).

---

## 🧠 Как это устроено (Архитектура памяти)

Программа избегает дорогостоящего копирования строк. Вместо этого весь файл загружается в память **один раз**, а структура данных строится на базе **двухуровневой адресации** через двойной указатель `LineInfo**`.

### Схема размещения данных в куче:

```text
file_info->indexes (LineInfo**)
      │
      ├──> [0] ───> Structure LineInfo ───> .line ──┐ (Указывает внутрь buffer)
      ├──> [1] ───> Structure LineInfo ───> .line ──┼──────┐
      └──> [2] ───> Structure LineInfo ───> .line ──┼──────┼──────┐
                                                    │      │      │
file_info->buffer (char*)                           ▼      ▼      ▼
      ┌───────────────────────────────────────────┬────┬──────┬────┬────┐
      │ Мой дядя самых честных правил...          │ \0 │ Когда│ не │ \0 │ ...
      └───────────────────────────────────────────┴────┴──────┴────┴────┘
```

1. **`buffer`** — содержит «сырой» текст. Символы `\n` на этапе парсинга заменяются на `\0`, превращая буфер в массив валидных Си-строк.
2. **`indexes`** — массив указателей на структуры. Каждая структура хранит точный адрес начала строки внутри `buffer` и её длину.

## 🛠 Реализованные режимы сортировки

Программа умеет выстраивать текст тремя разными способами:

*   **Прямая сортировка (Classic Sorter):** Сравнение строк по алфавиту от начала к концу. Игнорирует регистр символов и знаки препинания для честного лексикографического порядка.
*   **Обратная сортировка (Rhyme Sorter):** Сравнение строк **справа налево** (начиная с последнего символа). Идеально подходит для группировки стихов по рифмам и создания обратных словарей.
*   **Оригинальный текст (Restorer):** Вывод исходного текста (в том порядке, в котором он шел в файле) напрямую из оригинального буфера.

## ⚙️ Сборка и требования

Проект написан на чистом **ISO C** и не требует сторонних зависимостей.

### Требования
* Компилятор с поддержкой стандарта C11 (`gcc`, `clang` или `msvc`)
* Утилита `make`

### Инструкция
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd Onegin
   ```
2. Скомпилируйте проект с помощью `Makefile`:
   ```bash
   make
   ```
3. Запустите программу, передав ей текстовый файл:
   ```bash
   ./onegin evgeny_onegin.txt
   ```

## 🛡 Безопасность и утечки памяти

Программа спроектирована с учетом жестких требований к утечкам памяти. Любой вызов `calloc` строго проверяется на `NULL`. Освобождение ресурсов происходит по каскадному принципу:

```c
// Порядок очистки вложенных структур
for (int i = 0; i < file_info->lines; i++) {
    free(file_info->indexes[i]); // 1. Удаляем сами структуры
}
free(file_info->indexes);        // 2. Удаляем массив указателей
free(file_info->buffer);         // 3. Удаляем весь текст
```

Для проверки проекта на отсутствие утечек (memory leaks) использовалась утилита `Valgrind`:
```bash
valgrind --leak-check=full ./onegin input.txt
```
