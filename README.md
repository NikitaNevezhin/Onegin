# 📖 Проект «Онегин» (Onegin Sorter)

Проект представляет собой высокопроизводительный текстовый сортировщик на языке **C**, разработанный в рамках изучения низкоуровневой работы с памятью, указателями и строками в стиле Си. Основная задача программы — корректно считать текстовый файл (например, роман А. С. Пушкина «Евгений Онегин»), разбить его на отдельные строки и отсортировать их различными методами.

## 🚀 Ключевые особенности

- **Эффективный менеджмент памяти:** Весь файл считывается в единый непрерывный буфер (`char*`), минимизируя количество операций ввода-вывода (I/O).
- **Двухуровневая индексация строк:** Для работы со строками используется динамический массив двойных указателей (`LineInfo** indexes`), где под каждую строку выделяется своя структура с метаданными (адрес начала и длина).
- **Безопасная токенизация:** Программа заменяет символы перевода строки `\n` на нуль-терминаторы `\0`, разделяя буфер на честные Си-строки без дублирования данных в памяти.
- **Гибкая сортировка:** Поддерживает сортировку текста по алфавиту как с начала строки, так и с конца (для поиска рифм / составления обратного словаря).

## 🛠 Архитектура данных

Проект базируется на двух ключевых структурах данных:

```c
// Информация о конкретной строке
struct LineInfo { 
    char* line;    // Указатель на начало строки внутри общего буфера
    int length;    // Длина строки
}; 

// Контекст считанного файла
struct FileInfo { 
    int lines;           // Общее количество строк
    const char* filename;// Имя файла
    int size;            // Размер файла в байтах
    char* buffer;        // Единый буфер со всем текстом
    LineInfo** indexes;  // Динамический массив указателей на структуры строк
};
```

## 🏗 Сборка и запуск

Для сборки проекта вам понадобится компилятор `gcc` или `clang` и утилита `make` (если используется Makefile).

### Компиляция:
```bash
gcc -Wextra -Wall main.c -o onegin
```

### Запуск:
```bash
./onegin input.txt
```

## 🧹 Управление памятью

Проект строго следует правилам чистой работы с ресурсами. Поскольку память под структуры выделяется динамически на двух уровнях, её освобождение происходит вложенно:

```c
void FreeFileInfo(FileInfo *file_info) {
    if (file_info->indexes != NULL) {
        for (int i = 0; i < file_info->lines; i++) {
            free(file_info->indexes[i]); // Освобождение структуры строки
        }
        free(file_info->indexes);        // Освобождение массива указателей
    }
    free(file_info->buffer);             // Освобождение текстового буфера
}
```

## 📈 Планы по доработке (Roadmap)
- [ ] Интеграция алгоритма быстрой сортировки (QuickSort) вместо стандартной пузырьковой сортировки.
- [ ] Написание кастомных компараторов, игнорирующих знаки препинания и регистр символов при сортировке.
- [ ] Оптимизация выделения памяти: переход от двойного указателя `LineInfo**` к одномерному массиву структур `LineInfo*` для уменьшения фрагментации кучи (heap).
